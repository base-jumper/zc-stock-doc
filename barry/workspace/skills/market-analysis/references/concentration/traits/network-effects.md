# Trait: Network Effects

**Production role:** selected direct-ridge feature for both `s1` and `r`.

**What we're looking for:**
The product gets more valuable to each user as more users join, so the largest player's lead
compounds rather than erodes. Direct (users value other users: messaging, marketplaces) or indirect
(more users → more complements/liquidity → better product: app stores, two-sided marketplaces,
ad-funded search).

**Expected direction:** stronger network effects raise `s1` and lower `r`: value accrues
disproportionately to the biggest network, concentrating share at the top.

**Weakeners to check:**

* **Multi-homing** — if users cheaply use several providers at once (ridesharing, food delivery),
  the effect concentrates share far less than when the network is winner-take-all (a social graph).
* **Local vs global** — effects that saturate locally (regional marketplaces) support several
  regional leaders, not one global one.

**Scoring guidance (0–1, how strong the effect is):**

* **0.70–1.00** Strong, global, single-home network effects; the leader's advantage compounds
* **0.40–0.69** Real but bounded — indirect, regional, or eroded by multi-homing
* **0.00–0.39** Little or none; value is independent of how many others use it

**Documentation:** which mechanism (direct/indirect), single- vs multi-homing evidence, and whether
the effect is global or saturates locally.
