# Investment Thesis

## Overview
Each file in this folder is an investment thesis documented in markdown format. Each thesis makes a prediction about a theme that will play out in the future, and explores ways to benefit financially from it. This typically means identifying "winners" in the stock market that are positively impacted by the theme. 

The purpose of documenting the thesis is to allow an agent to:
* look for evidence that the thesis either is or isn't playing out as expected, so that our conviction in the theme can be updated on a regular basis to track reality as closely as possible
* identify new "winners" that were previously unknown
* watch for attractive entry points to winners that have been identified on themes which we have high conviction for.
* conversely, where conviction in a thesis has degraded we can watch for the most painless exit points.
